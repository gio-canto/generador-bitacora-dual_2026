# Generador de Bitácora Dual 2026

Aplicación web estática para crear bitácoras semanales de Educación Dual mediante un asistente paso a paso.

## Funciones

- Configuración universal de especialidad, semestre, grupo y periodo.
- Registro progresivo de alumno, plantel y empresa.
- Cuatro jornadas semanales con horario, área y actividades.
- Responsables y firmas.
- Guardado privado en el navegador.
- Impresión o exportación a PDF en A4 horizontal.
- Diseño responsivo, accesible y compatible con movimiento reducido.

## Uso local

Abre `index.html` en cualquier navegador moderno. No requiere instalación ni servidor.

## Publicación

El flujo incluido en `.github/workflows/pages.yml` publica automáticamente el contenido en GitHub Pages después de cada cambio en `main`.
