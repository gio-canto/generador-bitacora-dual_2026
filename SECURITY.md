# Política de seguridad

## Versiones compatibles

La rama **main** contiene la versión compatible y mantenida.

## Reportar una vulnerabilidad

No publiques información sensible, respaldos o datos de alumnos en un issue público.

Para reportar un problema:

1. Describe el comportamiento sin adjuntar datos personales.
2. Indica el navegador y la versión utilizados.
3. Explica los pasos mínimos para reproducirlo.
4. Señala si afecta el almacenamiento local, la importación JSON o el PDF.

## Alcance

El proyecto no procesa información en un servidor. Los principales riesgos corresponden al contenido importado, la exposición accidental de respaldos y las modificaciones no autorizadas del código publicado.
