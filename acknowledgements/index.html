Agradecimientos y dependencias

Reconocimiento a los proyectos, bibliotecas y herramientas que hacen posible el Generador de Bitácora Dual 2026.

Última actualización: 20 de septiembre de 2026

Gracias al software de código abierto

React y React DOM

Base de la capa de interfaz moderna y del montaje de componentes.

Sileo

Notificaciones breves integradas en determinadas acciones del sistema.

Blobatar

Generación local del avatar asociado al nombre recordado en el perfil.

nspell

Motor del corrector ortográfico local utilizado en actividades y justificaciones.

dictionary-es

Diccionario en español utilizado por el corrector ortográfico.

Phosphor Icons

Biblioteca de iconos incluida entre las dependencias del proyecto.

Herramientas de desarrollo y pruebas

El proyecto también se apoya en Vite, Vitest, Testing Library, user-event, jsdom, Prettier, el plugin de React para Vite y @napi-rs/canvas para compilar, probar, dar formato y verificar funciones como la generación del PDF.

Infraestructura

GitHub se utiliza para el repositorio y la colaboración del proyecto. GitHub Actions participa en la verificación y compilación, y GitHub Pages sirve la aplicación publicada.

Avisos de licencia incluidos

El repositorio conserva avisos específicos para componentes que lo requieren. Puedes consultar directamente la licencia de nspell y el aviso del diccionario español.

La licencia principal del proyecto se encuentra en el archivo LICENSE del repositorio. Cada dependencia conserva además los términos establecidos por sus propios autores y distribuidores.

Recursos del proyecto

El repositorio incluye recursos como el logotipo Edu.png, imágenes de ejemplo y archivos multimedia utilizados por funciones especiales de la interfaz. Su procedencia y permisos deben conservarse documentados por separado cuando corresponda; que un archivo esté dentro del repositorio no sustituye los derechos que puedan existir sobre ese recurso.

Personas que contribuyen

Gracias a quienes reportan errores, actualizan catálogos, prueban el generador o proponen mejoras. Si deseas colaborar, consulta la guía de contribución.
