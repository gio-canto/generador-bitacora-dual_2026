La bitácora deja de ser un archivo que tienes que reconstruir cada semana. Tus datos frecuentes pueden quedar preparados y tú te concentras en registrar las actividades que realmente realizaste.

Para la escuela

Un formato igual para todos. Un seguimiento más rápido para Vinculación.

Facilitarle la bitácora al alumno también ayuda al plantel: menos formatos alterados, menos archivos distintos y una forma más clara de saber quién entregó.

01 Facilita el proceso al alumno

Un flujo claro reduce la fricción de elaborar la evidencia semanal.

02 Estandariza las bitácoras

Todos parten de la misma estructura y del mismo formato institucional.

03 Evita cambios accidentales

El alumno no necesita mover celdas, márgenes o elementos del documento para poder llenarlo.

04 Controla entregas con rapidez

Vinculación puede registrar, filtrar y reportar entregas sin volver a capturar cada dato.

Tiempo aproximado

Menos tiempo llenando y registrando. Más tiempo para lo importante.

Comparación orientativa basada en el flujo esperado del proyecto. No es un benchmark formal: los tiempos reales cambian según la persona, el plantel y la cantidad de alumnos.

El proyecto

Tres herramientas para distintas partes del proceso.

El alumno no necesita una pantalla administrativa y Vinculación no necesita llenar la bitácora. Cada sistema hace una sola cosa y la hace de forma clara.

01

Alumnos

Generador de Bitácora Dual

Captura la semana, reutiliza información frecuente, conserva historial, muestra una vista previa y genera un PDF listo para revisión y firma.

02

Vinculación

Registro de entregas

Administra alumnos y semanas, escanea Data Matrix, distingue entregas a tiempo o a destiempo y genera listados y reportes globales.

03

Constancias

Sistema de gestión y emisión

Un sistema complementario para organizar la gestión y emisión de constancias de alumnos de modalidad dual y reducir otro trámite repetitivo.

La bitácora también puede identificarse sola.

El Data Matrix conecta el documento con el registro de entrega. Incluye la identidad necesaria para ubicar al alumno y el periodo correcto, sin guardar las actividades ni las firmas.

Un flujo simple

Crear. Entregar. Registrar. Reportar.

  1. 1
    El alumno crea

    Completa sus actividades y descarga la bitácora.

  2. 2
    La escuela recibe

    Escanea o registra la entrega manualmente.

  3. 3
    El sistema organiza

    Relaciona alumno, semana y estado de entrega.

  4. 4
    Vinculación reporta

    Consulta por semana o genera una matriz global.

Para instituciones

¿Quieres que tu institución pueda usar este sistema?

La idea es que el proyecto pueda crecer de forma autónoma. Un alumno, docente o plantel puede aportar directamente: agregar su escuela, empresa, responsable o una mejora completa sin tener que esperar a que alguien lo haga por ellos.

Ruta 1 · Colaborar

Tu escuela puede agregarse al proyecto.

Estudiantes, docentes o personal de Vinculación pueden editar los catálogos, agregar una escuela o empresa, corregir datos, crear una rama y enviar una pull request. Las aportaciones útiles son bienvenidas.

Colaborar en GitHub

Ruta 2 · Implementación acompañada

Si necesitan ayuda, también pueden pedirla.

Si el plantel no quiere tocar código, se puede revisar su formato, responsables, empresas, calendario, reglas de entrega y reportes para plantear una integración compatible con su procedimiento actual.

Pedir apoyo al creador ↗
La meta no es cambiar el procedimiento porque sí.

Es quitar captura repetida y conservar los controles que la escuela realmente necesita.

Cómo está construido

Privacidad.

El generador no necesita una cuenta para crear bitácoras. Los datos de trabajo, historial y registro se mantienen en el navegador o dispositivo y las exportaciones quedan bajo control de quien las descarga.

Leer aviso de privacidad ↗

Open source.

El código está disponible públicamente bajo la licencia del proyecto. Cualquier persona puede estudiarlo, proponer mejoras y colaborar mediante issues o pull requests. Un estudiante puede incluso proponer su propio plantel o actualizar un catálogo sin depender de una administración central.
