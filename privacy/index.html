Privacidad y datos

Política de privacidad

Cómo utiliza, guarda y protege la información el Generador de Bitácora Dual 2026.

Última actualización: 20 de septiembre de 2026

Resumen

Sin cuenta

No necesitas crear una cuenta ni iniciar sesión para elaborar una bitácora.

Guardado local

El borrador, el historial y el nombre recordado se almacenan en el navegador del dispositivo.

Sin analítica propia

La versión actual no integra publicidad, perfiles publicitarios ni herramientas propias de analítica de uso.

Sin cookies propias para la bitácora

El generador utiliza almacenamiento local y caché del navegador, no cookies propias para guardar tus registros.

La información que escribes en los campos de la bitácora no se envía a un servidor del proyecto para ser almacenada.

1. Información que utiliza el generador

Para crear el documento, la aplicación puede manejar datos como nombre del alumno, plantel, especialidad, grupo, empresa u organismo receptor, fechas, horarios, actividades y nombres o cargos de responsables. También guarda preferencias necesarias para recordar el tutorial, el perfil local y el estado del borrador.

Estos datos se utilizan para mostrar, guardar localmente y generar tu bitácora y su PDF.

2. Dónde se guarda

Los registros se conservan principalmente mediante localStorage en el mismo navegador y dispositivo. El generador también usa caché y un service worker para permitir que determinados recursos sigan disponibles sin conexión.

Cuando exportas un respaldo JSON o generas un PDF, el archivo queda bajo tu control en el dispositivo o en el destino que elijas al compartirlo.

3. Servicios y recursos externos

El sitio se publica mediante infraestructura de GitHub Pages. Como ocurre con cualquier sitio web alojado por un tercero, la infraestructura que entrega la página puede procesar datos técnicos necesarios para establecer la conexión, de acuerdo con sus propias políticas.

La pantalla de créditos incluye actualmente una imagen de perfil servida desde avatars.githubusercontent.com con la política no-referrer. Esta solicitud no incluye el contenido de tus actividades, bitácoras ni los campos del formulario.

Los enlaces a GitHub, DGETI, Modelo de Formación Dual, Instagram u otros sitios externos solo quedan sujetos a las políticas de esos servicios cuando los visitas.

4. Conservación y eliminación

La información local permanece mientras el navegador conserve los datos del sitio. Puedes eliminar registros desde el historial, usar Olvidar este nombre para borrar el nombre recordado del perfil y, si deseas retirar todo el almacenamiento restante del generador, borrar los datos del sitio desde la configuración de tu navegador.

El proyecto no mantiene una base de datos de bitácoras en un servidor, por lo que no puede recuperar ni eliminar a distancia información que solo existe en tu dispositivo.

5. Uso educativo y datos de estudiantes

El generador puede utilizarse en contextos educativos. No solicita la edad del usuario. Si tu plantel, empresa u organismo establece reglas adicionales sobre el tratamiento, entrega o resguardo de datos personales, esas indicaciones deben respetarse.

6. Cambios y contacto

Esta política puede actualizarse cuando cambien las funciones del generador, especialmente si en el futuro se incorporan servicios en línea, cuentas, analítica o almacenamiento remoto.

Para reportar una duda de privacidad o una discrepancia entre esta política y el funcionamiento real, abre un issue en GitHub.
